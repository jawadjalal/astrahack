# Questions and decisions

Awaiting user answers. Suggestions are not approved requirements.

## Needed to start

1. Who is the target customer, and which product should the first creatives promote? Is Gradlify the first use case?
2. Which destinations matter first: Meta ads, LinkedIn ads, app-store images, website banners, or something else?
3. Static images only, or also video? Which dimensions and how many variations per run?
4. What inputs will users supply: screenshots, product description, URL as reference, logo, brand colors, or visual examples?
5. Should output use faithful screenshots, generated imagery, or a mix?
6. What visual references define “clean and effective” for you?
7. What audience, main benefit, and call to action should the first creative use?
8. Should users approve concepts first or receive finished creatives immediately?
9. Which editing controls are essential: copy edits, colors, layout, or regeneration?
10. What is the hackathon deadline and required demo outcome?
11. Any preferred stack or hosting? Local demo or deployed product? Single operator or multiple users?
12. What cost and runtime per run are acceptable?
13. Will the provided credential be an OpenAI API key with API access? Configure it securely when implementation needs it.

## Before deployment

- Operator-provided API key or customer-provided keys?
- Upload and output retention/deletion rules?
- Required download formats?
- Demo only, or paid customer onboarding afterward?

## Suggested starting point

Static image creatives from supplied screenshots and a short product brief, with distinct concepts, readable composed text, targeted regeneration, and downloadable results. Formats, stack, budget, and approval steps remain open.
