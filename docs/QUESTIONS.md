# Decisions

- Input: a supplied prompt.
- Output: exactly five distinct square ad creatives per successful run.
- Dimensions: 1024×1024 pixels, 1:1 aspect ratio.
- Format: PNG images, no video.
- Channels: Facebook and Instagram.
- Style: clean and specific to the product.
- Implementation: a script and callable module; no website or app.
- API key: unavailable now; configure later.
- Validation without a key: dry run plus mocked API tests.

No further questions block implementation.
